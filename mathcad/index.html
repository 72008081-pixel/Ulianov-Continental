1. Operadores Booleanos en Mathcad Prime como Funciones de Heaviside

          
En Mathcad Prime 11, las comparaciones lógicas evalúan directamente a 1 (Verdadero) o 0 (Falso):

          

            (x ≥ a) = { 1 si x ≥ a, 0 si x < a }

            (b > x > a) = { 1 si a < x < b, 0 en otro caso }
          

          
Esto permite construir una sola expresión matemática continua para toda la viga sin requerir condicionales fragmentados ni macros.

        


        

          
2. ¿Por qué se quitan los brazos en la función de cortante Q(x)?

          
Por la relación diferencial de equilibrio estático fundamental en vigas de Euler-Bernoulli:

          

            Q(x) = dM(x) / dx
          

          
Al derivar cada término de momento respecto a la coordenada x:

          
    
            
  • Reacción vertical: d/dx [ VA · x ] = VA (el brazo lineal desaparece).
    • 
            
  • Carga uniforme activa: d/dx [ q · x² / 2 ] = q · x (la parábola pasa a variación lineal).
    • 
            
  • Carga uniforme superada: d/dx [ q · L · (x - L/2) ] = q · L (permanece la fuerza constante del tramo).
    • 
            
  • Carga puntual: d/dx [ P · (x - xp) ] = P (queda la fuerza puntual pura).
    • 
            
  • Momento concentrado aplicado: d/dx [ M ] = 0 (¡Un momento puro no produce fuerza cortante!).
    •
